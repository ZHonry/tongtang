# 同堂 · 使用手册

面向两类读者：**管理员**（部署并管理整套系统的人）和**家庭成员**（日常使用的人）。

---

## 一、首次配置（管理员）

1. 部署完成后打开 `http://服务器IP:8080`，进入首次配置向导
2. 填写 Home Assistant 地址（如 `http://192.168.x.x:8123`）、**长期访问令牌**（HA → 个人资料 → 安全 → 创建长期访问令牌）、管理员账号密码
3. 系统会自动测试连接并同步全部受支持的实体与房间（区域）

> 令牌只保存在服务端数据库中，前端与普通用户永远接触不到。

## 二、管理员工作流

管理后台入口：头像菜单 → 管理后台。

### 1. 整理实体（建议第一步）

设备管理 tab：
- 用 **显示状态 / 类型 / 房间 / 响应状态 / HA 实例**（多实例时出现）筛选器 + 搜索快速定位实体；「无响应」筛选可一键捞出失联实体，决定隐藏还是去 HA 修复
- 不想在控制端出现的实体点眼睛**隐藏**（重新同步也保持隐藏，可随时恢复）
- **多选批量**：勾选任意多个实体（或全选当前筛选结果）后批量隐藏/恢复——想保留一批里的一两个时，先全选再取消那几个即可
- HA 里新增了设备后，点**「同步实体与房间」**；同步是双向的——HA 端已删除的实体和房间会连带清理（权限、偏好、家庭设备集、表计一并处理）
- Zigbee2MQTT 等集成的**配置/诊断类实体**（指示灯、断电记忆、校准项）自动降级，不会出现在卡片主控位（详见 docs/device-recognition.md）

同一物理设备的多个实体会**自动组合**为一张卡片，无需配置；跨设备的组合（比如把不同品牌的两个开关拼成一张卡）用**「新建分组」**手动创建。

### 2. 家庭与多 HA

- **连接与家庭 tab → 附加 HA 实例**：接入第二个 HA（如父母家），填名称/地址/令牌，保存前自动测试；接入后同步、实时推送、控制自动覆盖
- **默认一个家庭对应一个 HA 实例**：添加实例时自动创建同名家庭并绑定，同步后该实例的设备/房间自动归入这个家庭，默认家庭圈定默认实例——各实例天然隔离，互不混杂（旧版本添加的实例会在下次同步时自动补建家庭）
- **跨 HA 控制**：手动新建一个家庭，「管理设备」里可从**任意 HA 实例**勾选设备划给它（带来源筛选）；只有手动建的家庭可以跨实例挑设备
- **家庭 tab**：每个家庭还可选择天气实体和新建房间写入的 HA
- 家庭是权限边界：给该家庭成员授权设备、配置电表时，候选范围被强制圈定在家庭设备集内；情景/自动化也跟随当前家庭所属的实例

### 3. 用户与权限

用户与权限 tab：
- **创建用户**：设置显示名称、登录账号、初始密码
- **复制成员配置**：新建用户时可选择已有成员，一键复制设备/房间授权、首页布局和个人能源配置；密码与个人资料需要单独填写
- **编辑成员**（铅笔图标）：改资料、**多选所属家庭**、绑定 HA 人员实体（用于"谁在家"）、**重置密码**（可随机生成）、停用/恢复登录
- **授权**：勾选该成员可见的房间与可控的设备；「在家状态互见」勾选哪些成员与其互相可见在家/外出状态
- 普通用户也可以自己创建子成员（见下文），子成员的权限永远是创建者权限的子集

### 4. 能源配置

能源配置 tab，**电 / 燃气 / 水**三类均为三级模型（下级优先）：
- **个人表**（user）：某个成员房间的独立表计，仅对该成员生效；保存时自动授权该成员
- **家庭表**（family）：整个家庭共用，保存时自动授权全家
- **全局总表**（global）：管理员汇总视角；不配置则自动汇总所有家庭+个人表

电表支持功率（W/kW 自动换算）、今日电量、累计电量三类实体多选求和；燃气/水直接选累计量实体。

> 电表没有独立的「今日用电」实体？「今日电量」留空即可——系统会按「累计电量」实体自动推算当日增量（实时读数减去当天 0 点的基线，基线来自 HA 长期统计），换表归零当天按 0 计、次日自愈。

**表计层级**（同 tab 的表计树）：总表 → 分表 → 挂接设备的树形分账。能源页按层级逐级下钻，父表减去下级之和显示为「未计量」；把某块表配置给用户，它就是该用户能源页的根节点——权限边界与计量边界合一。

**单价**：设置电/燃气/水单价后，能源页显示费用估算。

> 数据来源是 HA 长期统计（与 HA 能源仪表盘同源）：实体需要有 `state_class`（如 `total_increasing`）才会被 HA 记录统计，实时数值正常但历史为零通常就是缺这个属性。

### 5. 审计与备份

- 操作日志 tab：全量审计（登录、控制、授权、配置变更），右上角设置**保留时长**（30 天～永久），超期每日自动清理
- 备份：`GET /api/admin/backup` 返回核心配置 JSON；数据库文件位于容器卷（源码部署为 `home_console_data`，Docker Hub 镜像部署为 `tongtang_data`，含 `-wal` 文件一起备份）

## 三、家庭成员日常使用

### 卡片操作（与 Apple 家庭 App 一致）

| 操作 | 效果 |
|---|---|
| 点**图标** | 快捷开关：灯/开关直接切换；空调恢复上次模式；扫地机清扫↔回充；影音播放/暂停；窗帘全开全关 |
| 点**卡片其他区域** | 打开控制浮窗 |
| **长按**（或右键） | 同样打开控制浮窗 |
| 传感器/摄像头 | 点哪都是详情 |

浮窗内：灯光竖向滑条拖到底=关灯；组合设备底部有「一键操作/开关/调节/更多信息」分区和滤芯/电池寿命进度条。

### 首页

- 顶部分类胶囊（温控/灯/安全/…）点击进入对应类别视图
- 摄像头区显示快照（右下角是几秒前的画面），点开看实时
- 「谁在家」芯片显示已互见成员的在家/外出状态
- 房间名可点击，直达该房间

### 能源页

一级导航「能源」：电 / 燃气 / 水三个账本，日 / 周 / 月 / 自定义日期范围切换；构成环显示各来源占比，堆叠柱状图按设备分时展示，下方设备明细含费用估算。配置了表计层级时，点击构成环内的分表逐级下钻（面包屑返回），差值显示为「未计量」。

### 我的设备（头像菜单）

集中管理自己可见的全部实体：搜索、类型/房间/响应状态筛选；**多选批量**设置「首页显示/隐藏」——不常用的实体从首页收起来，需要时仍可在这里找到。

### 多家庭切换

属于多个家庭的成员，点侧栏**家名**（手机在头像菜单顶部）切换当前家庭 —— 设备、家名、天气、能源、自动化全部随之切换。

### 自助功能（头像菜单）

- **账户设置**：自己改显示名称、登录用户名、密码、**头像**
- **成员管理**（普通用户）：给家人创建账号、授权自己权限内的设备、重置其密码；新成员自动与你互见在家状态
- **个性化**：明亮/暗色/自动 · 七套风格（iOS 17 经典 / iOS 26 液态玻璃 / 金门 Golden Gate / 庭院新中式 / 夜航仪表舱 / 果冻多彩 / 素墨黑白，玻璃类含浓度滑杆）· 方块/胶囊卡片
- **关于**：项目简介与当前版本
- **自定义设备图标**：控制浮窗右下角齿轮 → 186 个内置图标或上传自己的图（单色图自动随主题着色）

### 互联平台（头像菜单 → 互联平台）

把自己有权限的设备接入第三方生态，各成员各绑各的账号、权限互不越界（权限被收回时设备自动从对方 App 消失）。三个页签，弹窗内都有分步操作手册：

**小爱同学 · 巴法云**（米家/小爱语音）：

1. 浏览器打开 [cloud.bemfa.com](https://cloud.bemfa.com) 注册巴法云账号（免费），进控制台复制右上角「用户私钥」
2. 弹窗里粘贴私钥点绑定 → 勾选设备 → 保存
3. 米家 App →「我的」→「其他平台设备」→ 添加「巴法」→ 用巴法云账号登录授权
4. 对音箱说「小爱同学，打开客厅灯」

支持灯/插座/开关/风扇/窗帘/空调/温湿度传感器，热水器映射为开关；指令走云端中转，偶有一两秒延迟属正常。

**涂鸦智能 · 虚拟网关**（涂鸦 App + 天猫精灵/小度等语音生态）：

1. 管理员在 [tuya.ai](https://tuya.ai/) 申请 API Key 填入（一次即可，全家共用）
2. 每人点「生成我的绑定二维码」，涂鸦智能 App（7.6.0+）首页右上角 ＋ → 扫一扫，扫码后点「我已完成扫码绑定」
3. 勾选设备保存 → 回涂鸦 App 在网关面板「添加子设备」里确认 → 设备成为家庭首页顶层设备（完整产品面板，按同堂房间自动归位）

支持灯（亮度/色温/彩色）、开关/插座、风扇、新风/净化、窗帘、空调（模式/风速/预设/扫风）、热水器、加湿器、扫地机、温湿度传感器与门磁（按物理设备整机接入，含电量）；每个网关最多 30 个子设备。

**HomeKit · 专属桥**（iPhone 家庭 App + Siri）：

1. 在设备列表勾选想接入的设备，点「保存勾选」——同堂自动创建一座只属于你的原生 HomeKit 桥（侧车承载；属于多个 HA 的家庭按实例各建一座）
2. iPhone 打开「家庭」App → ＋ → 添加配件 → 扫描页面上的二维码（或「更多选项…」手动输入配对码）
3. 完成！之后增删勾选自动同步进家庭 App、无需重新配对；权限被收回的设备自动消失

支持灯、开关、恒温器、风扇、窗帘/门窗、门锁、加湿器、热水器、安防面板、扫地机、阀门、电视（信源/遥控/音量）、门铃与无线按钮、情景/脚本/自动化（触发开关）与温湿度/照度/人体/门磁/烟感/土壤湿度等常见传感器；摄像头暂不支持桥接（可在 HA 侧用其 homekit 集成自行接入）。注意：配对时 iPhone 需与同堂服务器同一局域网（侧车经 mDNS 广播桥），离家控制需家中有 HomePod / Apple TV 做家庭中枢；每人配进**自己**的 Apple「家庭」（Apple 家庭内部不区分成员设备权限）。

> **配件数量**：单桥约 150 配件上限（超限保存时会提示分桥）；可按房间/类型自建多座桥并命名，设备在桥间挪动会在家庭 App 中重建（保存前有确认）。
**开通方式与排障（原生侧车）**：compose 中预置两种开通方式二选一——方式 A 取消 `docker.sock` 挂载行注释（自动编排侧车）、方式 B 取消 `hk` 服务整段注释（compose 静态创建，不碰 docker.sock，api 端无需任何开关）。方式 A 为**零配置开通**——第一次建桥时同堂自动创建 tongtang-hk 侧车容器（host 网络、复用镜像与数据卷），全部桥删除后自动回收，镜像升级后自动重建侧车。能力：**同一物理设备整机一块磁贴**（PDU 插排展开各口、温湿度电量合一、多灯合并、新风→净化器卡片；外层磁贴显示设备名，展开后的子控件显示各实体名），热水器可接入，家庭 App 操作经同堂权限校验并记入审计。HomeKit/Matter 桥接需要 host 网络（NAS/Linux Docker）；Docker Desktop（Windows/macOS）不支持 host 网络，无法使用 HomeKit/Matter 桥接。docker.sock 等同宿主机管理权限，介意可用 docker-socket-proxy 收紧。排障：配对最后一步失败或配件一直"未连接"，多为宿主机多网卡/虚拟网卡（WireGuard 等）导致 mDNS 通告错 IP——设置 `HK_ADDRESS` 为局域网 IP（方式 A 设在 api 环境变量自动透传，方式 B 设在 hk 服务）；桥端口被占会自动迁移空闲端口、配对无损；iPhone 需与服务器同网段（跨段需路由器开 mDNS 反射）。Zigbee2MQTT 用户：无线按钮需在 Z2M 配置开 `homeassistant: experimental_event_entities: true` 才有实体可勾；Z2M 插座不带 outlet 类，按名称自动识别，识别不到用"显示为"手选。

### 情景与自动化

「自动化」页统一管理 HA 原生情景与自动化（只显示自己创建的；管理员可见全部）：
- 新建情景：捕获所选设备当前状态，一键还原
- 情景保留空调模式与温度、窗帘开度、门锁状态和灯光颜色等原生属性；离线设备及按钮不参与状态捕获。
- 新建自动化：时间/状态触发 + 多动作 + 动作间延时 + 时间段条件；复杂逻辑用「高级编辑」直改 HA 原生 JSON
- 普通成员的高级编辑仅接受可明确校验权限的设备目标，触发器、条件和嵌套动作都会检查授权。模板、区域/设备/标签批量目标、脚本调用等无法限定设备范围的配置由管理员管理。
- 通过成员授权面板收回设备权限时，受影响的 HA 原生自动化会先停止并设为停用；若 HA 无法完成停用，授权修改会返回错误并保留原权限。情景执行和 HomeKit 触发也会重新检查当前授权。
- **多家庭**：列表与创建都跟随当前家庭所属的 HA 实例——在哪个家庭上下文里建，就写进哪个 HA；一条情景/自动化不能混用不同实例的设备

## 四、常见问题

**Q：页面数据不动了？**
右上角网络断开时会自动降级为 30 秒轮询并自动重连；强刷（Cmd/Ctrl+Shift+R）可强制更新前端版本。

**Q：新接的设备没出现？**
管理后台点「同步实体与房间」；若是新类型设备，确认其域已受支持（见 README 功能列表）。

**Q：成员说少了设备？**
依次检查：实体是否被隐藏 → 是否在其家庭设备集内 → 是否已授权给该成员 → 其当前切换的家庭是否正确。

**Q：忘记管理员密码？**
用另一个管理员重置；只有一个管理员时，删除数据卷重新初始化（会丢配置），或直接改库中 `users.password_hash`。
